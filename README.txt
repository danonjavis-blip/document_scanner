СКАНЕР ДОКУМЕНТОВ (локальный сайт)
=================================

1. РАСПАКОВКА
   Распакуйте папку scanner_project в домашнюю директорию:
       ~/scanner_project

2. УСТАНОВКА ЗАВИСИМОСТЕЙ (один раз, в терминале):
   sudo apt install python3-pip
   pip install --user --break-system-packages flask pymupdf pillow \
        scikit-image opencv-python imutils pillow-heif

3. ИКОНКА В МЕНЮ ПРИЛОЖЕНИЙ
   а) В файле docscanner.desktop замените ВАШ_ПОЛЬЗОВАТЕЛЬ
      на имя вашего пользователя (то, что выводит команда `whoami`).
   б) Скопируйте файл в приложения:
      cp docscanner.desktop ~/.local/share/applications/
   в) Нажмите Super (Windows-клавиша), введите «Сканер» —
      иконка появится в Show Apps.

4. ЗАПУСК
   Нажмите на иконку — откроется Firefox со страницей сканера.
   Сервер работает, пока открыта страница: закрыли вкладку/браузер —
   сервер сам выключится. Повторное нажатие иконки просто откроет
   страницу заново.

5. КАК ПОЛЬЗОВАТЬСЯ
   - Кнопка «Выберите файлы» — загрузка фото (jpg, png, heic, pdf,
     несколько за раз).
   - «Сканировать всё» — обработка всей очереди.
   - Если документ не распознан автоматически, внизу появится кнопка
     «Указать углы» — кликните 4 угла листа на фото.
   - Сканы сохраняются в PDF в папку scanned/ проекта.
   - Оригиналы после успешного сканирования переносятся
     в need_to_scan/done/.

СТРУКТУРА
   scanner_app.py    — веб-сервер (Flask)
   scan_logic.py     — логика сканирования (OpenCV)
   pyimagesearch/    — модуль трансформации перспективы
   templates/        — страницы сайта
   need_to_scan/     — очередь загрузки (+ done/ — обработанные)
   scanned/          — готовые сканы (+ thumbs/ — миниатюры)
   scanner.log       — лог сервера
